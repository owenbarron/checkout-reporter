Checkout Reporter

A browser-based tool for exporting checkout data securely from the USEFULL admin panel

Drag once. Sync whenever needed.

Drag the teal button into your browser’s bookmarks bar. Do not click it on this page.

Checkout Reporter

If the bookmarks bar is hidden, use your browser’s View menu to show it.

Browser support: Desktop Chrome is tested. Current versions of Edge, Brave, and Firefox are expected to work. Safari and mobile browsers have not been tested.

  1. Open AssignmentsSign in to the USEFULL admin panel and open the Assignments page.
  2. Sync new checkoutsClick the Checkout Reporter bookmark, then click Sync new checkouts. The reporter refreshes the table automatically.
  3. Download report filesChoose location, container type, both, or neither for daily totals. Download the Transaction Log for individual timestamps, users, and containers.
Local by design. Checkout rows are deduplicated by assignment ID and retained only in that browser profile. The login token is used in memory for the active sync and is never written to storage or included in exports.
